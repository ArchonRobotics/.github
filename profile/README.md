# Building Whole-Body Intelligence (WBI)

At Archon Robotics, we're building a **Humanoid Foundation Model (HFM)** for whole-body intelligence - the foundational AI layer that lets humanoid robots **move, perceive, reason, and act in the real world**.

[![Whole-Body Intelligence](./landing.jpg)](https://youtu.be/b0h9oC8FhpU)

**Whole-Body Intelligence (WBI)** is our framework for building generalist humanoid foundation models.

- **Context-aware behavior.** A behavioral foundation model for precise, stable loco-manipulation with terrain interaction.
- **Learning from human motion.** Pre-training on large-scale whole-body human data builds rich interaction priors.
- **Learning on real robots.** Efficient post-training with real-robot data turns pretrained knowledge into skills.
